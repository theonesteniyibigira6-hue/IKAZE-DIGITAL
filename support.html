Troubleshooting

Common problems, first steps

Before submitting a request, try these steps — they solve most issues.

Website Not Working?

  1. Check your internet connection.
  2. Refresh the page (Ctrl/Cmd + R).
  3. Try a modern browser (Chrome, Firefox, Edge, Safari).
  4. Clear cached page data if you have persistent errors.
  5. Try another device or network to confirm.
  6. Note the exact error and page URL.
  7. Submit a support request with those details.

Tool Not Updating?

  1. Reload the page and try again.
  2. Re-type or re-paste your text into the input.
  3. Confirm JavaScript is enabled in your browser.
  4. Try a different browser (Chrome, Firefox, Safari).
  5. Try a different device to isolate the problem.
  6. If it still fails, submit a Tool Problem report.

Opportunity Link Broken?

  1. Copy the official source URL from the opportunity card.
  2. Paste it directly into your browser (not a tracking link).
  3. Check if the deadline has passed — some sources archive after closing.
  4. Search the organization's site directly.
  5. Report the issue from the opportunity page or via support.

Cannot Reach Contact?

  1. Use the contact form on contact.html.
  2. If email bounces, re-check the address for typos.
  3. Try the support form below if the contact form fails.
  4. Note: we do not offer live chat or phone support at this time.

Report a Security Concern

Responsible Disclosure

If you believe you have found a security vulnerability in an IKAZE DIGITAL service, please report it responsibly. Do not exploit it.

What to include: Affected service, steps to reproduce, potential impact, and any safe evidence.

What NOT to include: Passwords, private keys, API secrets, authentication codes, personal data of others.

Email Security Team

We do not currently offer a bug bounty program. We appreciate responsible disclosure and will acknowledge serious reports where we are able.
